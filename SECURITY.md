# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in the AI Data Summarizer, please report it privately using **GitHub's Security Advisories**:

1. Go to the [Security tab](https://github.com/Bloomy52/ai-data-summarizer/security) of this repository
2. Click "Report a vulnerability"
3. Provide details about the vulnerability

**Please do NOT create a public issue for security vulnerabilities.**

This allows us to work on a fix and coordinate disclosure before the vulnerability is made public.

## Privacy & Data Handling

This app does use AI for interpretations of the dataset summary generated by pandas. There is an option in the program to use pandas summarization only if you choose to use that. All data summarization via pandas is done on your machine locally.

## Supported Versions

Only the latest version is actively maintained. Please upgrade to the latest version for security patches.
